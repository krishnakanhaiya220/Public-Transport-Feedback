# 🚌 Public Transport Feedback Portal

## 📌 About the Project
The **Public Transport Feedback Portal** is a web-based application designed to collect feedback from passengers and help improve public transportation services.

Passengers can share their experiences, submit complaints, report issues, and provide ratings about public transport services. The portal also helps administrators manage feedback and monitor service quality.

## 🎯 Objectives
- Make public transport feedback easy and accessible.
- Improve the quality of transportation services.
- Allow passengers to report problems and complaints.
- Support accessibility for all passengers, including persons with disabilities.
- Help authorities understand passenger needs.

## ✨ Features
- **Feedback Submission:** Passengers can submit feedback and suggestions.
- **Route and Stop Selection:** Select transport routes and stops.
- **Issue Categories:** Report different types of transportation problems.
- **Rating System:** Rate public transport services.
- **Feedback Status:** Track submitted feedback.
- **Admin Dashboard:** View and manage passenger feedback.
- **Accessibility:** Designed to support passengers with different accessibility needs.
- **Responsive Design:** User-friendly interface for different screen sizes.

4. Run the project using Live Server.
5. Explore the Public Transport Feedback Portal.
